## ✨ Overview

Controllable Marble Maze is an Arduino-based robotics project that transforms a traditional marble maze into an interactive game controlled by a joystick.

The project was developed for **"Sci on the MOVE" (Science Week)** as part of my **Grade 10 Computer and Robotics** course. Players use a joystick to tilt the maze in four directions, guiding a marble from the starting point to the goal while avoiding obstacles.

The project demonstrates the integration of mechanical design, Arduino programming, servo motor control, and analog input processing to create a fun and engaging physical game.

## ⚙️ How It Works

The maze is mounted on a platform driven by **two servo motors**, each responsible for one axis of movement.

A joystick provides analog input to the Arduino, which converts the joystick position into servo movements. By tilting the platform forward, backward, left, or right, players control the marble's movement through the maze.

The objective is simple:

> Guide the marble from the start to the finish without falling into obstacles.
